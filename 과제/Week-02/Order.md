# AI 활용 보고서 — SwiftUI 화면 구조와 상태 과제

## 1. AI를 활용한 방식

과제 전체(자기소개 카드, 수식어 순서 비교, 카운터, 아이콘 목록)에 대한
초안 코드를 Claude에게 요청하여 기본 구조를 잡은 뒤, 직접 작성했던
ContentView 코드를 제시하고 그것이 과제 요구사항에 얼마나 부합하는지
점검받는 방식으로 활용했다.

## 2. 사용한 프롬프트

1. 본인이 직접 작성한 ContentView 코드를 붙여넣고
   "이 코드 가지고 2번 과제 수행해줘"라고 요청 → 본인 코드의 텍스트/
   패딩/배경 스타일을 그대로 활용한 OrderCompareView 코드로 변환받음

2. "내가 작성한 코드는 1번 과제에 부합해?"라고 질문 → 본인이 작성한
   ContentView가 1번(자기소개 카드) 요구사항 중 무엇을 충족하고
   무엇이 빠졌는지 구체적 피드백을 받음

## 3. AI가 제시한 결과물

- **1번 피드백**: 본인 코드는 배경색·모서리 둥글기·VStack 사용은
  충족했으나, (1) 아이콘 부재, (2) HStack이 비어 있어 실질적으로
  안 쓰인 점, (3) 이름/학과/소개가 하나의 Text로 뭉쳐 있는 점을
  지적받았고, 이를 반영한 개선 코드(HStack으로 아이콘+텍스트 묶기,
  ZStack으로 배지 추가)를 받음

## 4. 본인의 개선사항 (AI 결과물과의 차이)

- AI가 제안한 아이콘(`person.crop.circle.fill`) 대신 실제
  전공(게임공학과)을 더 잘 드러내는 `gamecontroller.fill` 아이콘으로 교체함
- `.background(.yellow)` 배경을 추가하고 모서리 라운드를 적용함
- 카드 배경색을 `.yellow` 대신 팀 컬러인 `.mint`로 변경하고
  텍스트 대비를 위해 `.foregroundColor(.black)` 추가
